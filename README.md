# Skunkworks USA Website

Static landing page for Skunkworks USA.

## Domain

https://skunkworksus.com

## Purpose

Skunkworks USA is the US regional landing page for secure AI, cloud, cybersecurity, infrastructure, digital transformation, and workforce enablement.

## Structure

- `index.html` — production landing page
- `styles.css` — shared Skunkworks design system, mirrored from Skunkworks Africa
- `adaptive-shell.css` — adaptive header and footer shell treatment
- `hero-chat.css` — assistant/search prompt UI
- `site.js` — mobile navigation and prompt routing
- `site-map.json` — route governance and navigation model
- `robots.txt` — crawler rules
- `sitemap.xml` — search sitemap
- `assets/` — logo and favicon assets
